# SteamCleaner
*A tool to clean your Steam installation. In case you messed up or left it full of shitt*

Tool created to clean faulty or corrupted Steam installations (for those people who like to leave their Steam installation a mess).
This is specifically for users who have modified their Steam client—using tools like Millennium, LuaTools, SkyTools, SteamTools, or any other existing tool. *(Seriously, why are there so many ._.?)*

Some Steam tools aren't compatible with one another; for instance, you can't mix SteamTools and LuaTools. One will end up overwriting the other, causing everything to glitch out. That’s exactly why I created this tool :D

***PowerShell command:***

```
irm "https://raw.githubusercontent.com/RazDays/SteamCleaner/main/clean.ps1" | iex
```

**IMPORTANT:** You must have .NET 8.0 to run this
Link: https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-desktop-8.0.30-windows-x64-installer
